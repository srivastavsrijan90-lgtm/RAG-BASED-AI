# HOW TO USE THIS RAG AI TEACHING ASSISTANT ON YOUR OWN DATA

## STEP 1 -- COLLECT VIDEOS 
MOVE ALL YOUR VIDEOS FILES TO THE  VIDEOS FOLDER

## STEP 2 -- VIDEO CONVERT TO MP3
CONVERT ALL THE VIDEO FILES TO MP3 BY RUNNING PROCESS_VIDEO.PY

## STEP 3-- CONVERT MP3 TO JSON
CONVERT ALL THE MP3 AUDIO TO TEXT(JSON FILE) USING VOICE_TO_TEXT.PY

## STEP 4 --- CONVERT JSON FILE  TO VECTORS
USE THE FILE MAKINGCHUNKS.PY  TO CONVERT THE JSON FILE TO A DATAFRAME WITH EMBEDINGS AND SAVE IT AS A JOBLIB PICKLE

## STEP 5 --PROMT GENERATION AND FEEDING TO LLM
READ THE JOBLIB AND LOAD  IT INTO THE MEMORY . THEN CREATE A RELEVANT PROMT AS PER THE USER QUERY AND FEED TO THE LLM(LARGE LANGUAGE MODEL)
